# Pulse AI (Pulse-Ai-Prod)
**Tagline:** Behavioral Spending Telemetry & Analytical Twin.

## Executive Summary
Pulse AI is the store-ready flagship build of the DTE Ecosystem. It maps Plaid financial telemetry to behavioral psychology signals, identifying spending "triggers" through the Nova AI coaching layer.

## Core Architecture
- **Backend:** FastAPI, PostgreSQL, Prisma
- **Frontend:** React 18, PWA (Vite PWA)
- **AI Engine:** Anthropic Claude 3.5 Sonnet (Nova)
- **Telemetry:** Plaid Link Integration

## Key Features
- **Spending Velocity:** Real-time tracking of daily burn rates against baselines.
- **Trigger Detection:** AI-driven identification of emotional/habitual spending drifts.
- **Store-Ready PWA:** Optimized for mobile-home-screen persistence with auto-update SW.

## Data Integrity & Security
- **Hardening:** Row Level Security (RLS), SSL Verification, JWT Secret Guard.
- **Privacy:** Secure, transient AI sessions ensuring data sovereignty.
