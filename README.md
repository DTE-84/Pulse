## 📋 Executive Overview

**Pulse AI** is the flagship behavioral intelligence engine within the DTE Ecosystem. Engineered for the next generation of wealth management, Pulse transforms raw financial telemetry (via Plaid) into high-fidelity behavioral signals. By mapping transaction velocity against psychological "triggers," Pulse provides a deterministic analytical twin for navigating modern capital environments.

---

## 🛠 Strategic Architecture

Pulse is built on a **High-Performance Unified Nexus**, ensuring sub-millisecond data ingestion and surgical precision in AI categorization.

### Technical Stack
- **Core Engine:** Node.js / Express (Async Pipeline)
- **Database:** PostgreSQL (Cloud Nexus) with Row Level Security (RLS)
- **AI Intelligence:** Anthropic Claude 3.5 Sonnet (Nova Analytical Layer)
- **Data Acquisition:** Plaid Link (Read-Only Telemetry)
- **Visual Layer:** React 18 / Vite / Tailwind CSS (Lux Forest Aesthetic)
- **Distribution:** Enterprise-Grade Progressive Web App (PWA)

## 🚀 Key Performance Indicators (Features)

### 1. High-Fidelity Ingestion
A multi-stage pipeline that sanitizes, validates, and enriches financial data.
- **AI Categorization:** Automated risk scoring (Essential, Lifestyle, Impulse, Critical).
- **Signal Extraction:** Identifying emotional catalysts like "Stress" or "Late Night" spending.
- **CSV Wrangler:** Legacy data ingestion with automated imputation logic.

### 2. Nova: The Analytical Twin
Nova isn't a chatbot; it's a behavioral coach synchronized with your financial pulse.
- **Dual Protocols:** Choose between *Gentle*, *Balanced*, or *Driven* coaching logic.
- **Contextual Awareness:** Nova analyzes real-time stats (Balance, Velocity, Delta) to provide actionable insights.
- **Privacy First:** Transient sessions ensuring total data sovereignty.

### 3. Professional PWA Interface
Optimized for mobile-home-screen persistence with high-fidelity performance.
- **Cinematic Analytics:** Growth trajectory charts and behavioral stress indices.
- **Adaptive UX:** Fully responsive across all device tiers (iPhone SE to Ultra-Wide Desktop).
- **Service Worker Core:** Auto-updating logic for 100% environment uptime.

## 🛠 Development & Uplink

### Prerequisites
- Node.js >= 22.x
- PostgreSQL Instance
- Environment Keys (Plaid, Anthropic, Supabase, Stripe)

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/dte-84/PulseAi-Prod.git

# 2. Install dependencies
npm install

# 3. Initialize Environment
cp .env.example .env

# 4. Boot Dev Environment
npm run dev
```
